# Documentação acadêmica do SIGDEI

Esta pasta guarda o cronograma, documentos de planejamento e materiais de apresentação do projeto interdisciplinar da Fundação Hermínio Ometto (FHO). Esses arquivos descrevem a proposta e o escopo da época em que foram produzidos.

A instalação, a arquitetura em uso, os controles de acesso e as fórmulas dos indicadores estão no [README atual](../README.md).

A distribuição foi revisada para excluir anexos com identificadores acadêmicos pessoais.
